Impact

Results that
actually matter.

01
NovaPay
Fintech · Series B
Problem

Payment processing latency spiking to 8–12 seconds during peak hours due to synchronous third-party integrations and no queue isolation. Revenue at risk: $2.4M/month.

Solution

Redesigned integration layer with async event-driven architecture. Introduced priority queue isolation between payment types. Implemented circuit breakers and adaptive retry with exponential backoff.

Tech Stack
Go Kafka Redis PostgreSQL Kubernetes
Result

p99 latency: 12s → 180ms. Zero peak-hour failures for 6 consecutive months. Unlocked Series B close by demonstrating infrastructure reliability.

02
Orion Cloud
Infrastructure · Enterprise
Problem

80 engineers spending ~35% of their time on infrastructure configuration and debugging environment inconsistencies. Slow onboarding (3 weeks per hire) blocking team growth.

Solution

Built an internal developer platform exposing infrastructure through a composable primitive API. Self-service environment provisioning, integrated observability, and runbook automation. Engineers write intent; platform handles execution.

Tech Stack
Rust Terraform CDK Backstage Prometheus Temporal
Result

Engineer onboarding: 3 weeks → 2 days. 34% reduction in infra-related incidents. Platform now serves 140+ engineers with no dedicated ops headcount.

03
Meridian AI
AI Infra · Seed → Series A
Problem

ML inference costs scaling linearly with users — no caching, no request deduplication, no adaptive batching. $180K/month GPU spend with 40% utilisation.

Solution

Designed a semantic caching layer in front of inference endpoints. Embedding-similarity lookup to reuse recent results within configurable drift threshold. Dynamic request batching with deadline-aware scheduling.

Tech Stack
Python Qdrant Triton NVIDIA A100 Ray
Result

GPU utilisation: 40% → 87%. Monthly inference cost reduced by 61%. Cache hit rate: 52% on production traffic. Directly extended runway by 8 months.

Vision

Infrastructure is
strategy.

01

Systems outlive products.

The companies that win the next decade aren't building features — they're building the substrate that makes a category of features possible. Infrastructure is compounding leverage.

02

AI needs a new primitive layer.

Current infrastructure was built for deterministic workloads. AI inference is stochastic, latency-sensitive, and cost-volatile. That gap is where we're building.

03

Complexity is a moat.

The hardest engineering problems are hard because they require years of nuanced context. I build systems where that complexity is invisible to the teams running on top of them.

04

Precision over velocity.

I don't build fast — I build right the first time, then iterate fast. The cost of rearchitecting core infrastructure is always measured in months, not sprints.
